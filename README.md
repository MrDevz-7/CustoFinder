# CustoFinder

Sistema de prospección inteligente de clientes para freelancers/agencias de
software. Descubre negocios locales sin sitio web (OpenStreetMap), los
evalúa con IA (Gemini), analiza a su competencia local (Playwright), y
lleva el seguimiento del pipeline de ventas.

**Estado actual: Día 5 de 7.**

100% gratis, sin tarjeta de crédito en ningún paso del proyecto.

## Estructura

- [`backend/`](./backend/README.md) — FastAPI + PostgreSQL + SQLAlchemy.
  Setup completo, endpoints, variables de entorno, Gemini, OpenStreetMap,
  Playwright.
- [`frontend/`](./frontend/README.md) — Next.js + TypeScript. Búsqueda de
  negocios, kanban de pipeline, detalle de lead.
- [`docs/`](./docs/) — Informes de cierre y checklists de cada día de
  desarrollo.
